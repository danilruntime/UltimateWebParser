# VNC-киоск — план реализации

Спека: [`specs/2026-11-21-vnc-kiosk-design.md`](../specs/2026-11-21-vnc-kiosk-design.md)
(утверждена 2026-11-21).

Цель: VNC-ссылка открывает одно окно Chromium на весь экран, без вкладок,
адресной строки, панели и меню fluxbox и без DevTools. `fluxbox` остаётся и
работает фильтром клавиатуры.

## Файловая структура

| Файл | Ответственность |
| --- | --- |
| `src/uwp/vnc.py` | флаги браузера входа, конфиг fluxbox, список перехвата |
| `tests/unit/test_vnc_kiosk.py` | закрепляет kiosk-флаги и точный набор перехвата |
| `tests/unit/test_vnc.py` | поправленные ожидания полного стека и `$HOME` fluxbox |
| `README.md`, `README.ru.md` | что видит админ по ссылке |
| `docs/README.md`, `docs/README.ru.md` | раздел «VNC-сессии в подробностях» |
| `docs/superpowers/specs/2026-11-14-...md` | пометка, что панель отменена |

`src/uwp/profiles.py` не меняется: `--kiosk` — аргумент только VNC-стека,
парсеры запускаются headless и остаются как есть.

## Задача 1. Заморозить намерение в падающих тестах

Новый файл `tests/unit/test_vnc_kiosk.py`:

1. `test_kiosk_flag_replaces_the_window_size` — в аргументах браузера есть
   `--kiosk`, а `--window-size=1920,1080` и `--window-position=0,0` указывают
   на весь экран, не на рабочую область.
2. `test_fluxbox_grabs_every_escape_chord` — набор сочетаний в
   `_GRABBED_CHORDS` совпадает с эталонным (эталон — множество в тесте),
   и каждая строка `keys` заканчивается на ` :Exec true`.
3. `test_fluxbox_leaves_the_page_keys_alone` — `F5`, `Control r`,
   `Mod1 Left`, `Mod1 Right` не перехвачены.
4. `test_fluxbox_keys_use_a_command_fluxbox_accepts` — нет `:Noop`, `:None`,
   `:MacroCmd`; пустых команд нет.
5. `test_fluxbox_home_has_no_panel_and_an_empty_menu` — `init` без
   `toolbar.height/placement/tools`, с `toolbar.visible: false`, `keyFile`,
   `menuFile`, `workspaces: 1`; файл `menu` пуст.
6. `test_fluxbox_home_writes_the_keys_file` — `keys` совпадает с
   `_FLUXBOX_KEYS`.

Прогнать: тесты падают (атрибутов и `--kiosk` ещё нет).

## Задача 2. `src/uwp/vnc.py`

- Удалить `TASKBAR_HEIGHT`, `WORKAREA`; комментарий к `DESKTOP_SIZE` = 1080p,
  который kiosk занимает целиком.
- `_FLUXBOX_INIT`: `styleFile`, `appsFile`, `menuFile`, `keyFile`,
  `defaultDeco: NONE`, `toolbar.visible: false`, `workspaces: 1`. Без
  `toolbar.height/widthPercent/placement/tools/strftimeFormat`.
- `_FLUXBOX_MENU = ""`.
- `_GRABBED_CHORDS: tuple[str, ...]` — ровно список из §5.2 спеки.
- `_FLUXBOX_KEYS = "".join(f"{chord} :Exec true\n" ...)`.
- `_write_fluxbox_home(home: Path) -> Path` без `toolbar_height`; пишет
  `apps`, `init`, `menu`, `keys`, при исключении чистит каталог.
- В фабрике: `window_size=DESKTOP_SIZE` (замерено: без него kiosk с
  `--fingerprint` встаёт 945×1060 в углу); команда браузера
  `[executable, *args, "--kiosk", url]`.

Комментарии — почему, с замерами: kiosk сам блокирует DevTools и контекстное
меню, но `Ctrl+N` в kiosk открывает обычное окно 1050×760; `:Noop` fluxbox
считает ошибкой и теряет перехват.

## Задача 3. `tests/unit/test_vnc.py`

- `test_desktop_geometry_matches_windows_10` → `test_desktop_size_is_1080p`
  (панели больше нет, рабочая область не нужна).
- `test_fluxbox_home_sets_the_toolbar_and_strips_decorations` →
  `test_fluxbox_home_hides_the_panel_and_the_menu` (значения из задачи 1).
- `broken_fluxbox_home(home, toolbar_height)` → `broken_fluxbox_home(home)`.
- Полный стек: ждём `--kiosk`, `--window-size=1920,1080`,
  `--window-position=0,0`; Xvfb по-прежнему `1920x1080x24`.
