# Release 1.0.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `1.0.0` with four real defects fixed, install and disclaimer docs in two languages, and a release script that understands three-part versions.

**Architecture:** No new modules and no refactoring. Each defect is a local change guarded by a test that fails first. Documentation adds two EN/RU pairs, registered in the existing translation test. The release script grows a grammar and two kinds behind its pure `compute_next` function.

**Tech Stack:** Python 3.12+ (`aiosqlite`, `fcntl`), bash 5 (`scripts/release.sh`), pytest, ruff, Docker Compose.

**Spec:** `docs/superpowers/specs/2026-11-23-release-1.0.0-design.md`

## Global Constraints

- Tests first: every defect fix lands with a test that failed before it.
- `ruff check src tests` only; never `ruff format`.
- Line length 88 in new code, but do not reformat existing files.
- Comments explain *why*, with measurements when there was one.
- Human-facing strings in Russian in the bot/CLI; new project documents in EN + RU pairs.
- Migrations are append-only; this plan adds no migration.
- Version `1.0.0` must equal in `pyproject.toml` and `src/uwp/__init__.py`.
- Release notes `docs/releases/v1.0.0.md` are English.
- Do not touch `docs/images/vnc-desktop.png` (dirty from the operator).
- Run everything with `.venv/bin/python`.

## Review Focus

- A second process starting at the same time as the first: both call `migrate()`, and neither may crash or double-record a version.
- A `CONNECT` target written the way glibc accepts it (`127.1`, `0x7f000001`, `0177.0.0.1`, `2130706433`) must not reach `169.254.169.254` or the Docker socket.
- A healthcheck on a slow Telegram proxy must not flip a healthy container to unhealthy.
- An operator who runs the exact command the error message suggests must not end up in a loop.
- `./scripts/release.sh major` on `0.1b3` must produce `1.0.0` and the notes file must satisfy the release test.

**Files:**

**Interfaces:**

- Produces: `Database.migrate() -> None` unchanged; new private
  `Database._migration_lock() -> AsyncIterator[None]`; lock file
  `<db path>.migrate.lock` (mode `0600`, never deleted).

The lock is `fcntl.flock(LOCK_EX | LOCK_NB)` retried with `await asyncio.sleep(0.05)`
because `executescript` cannot hold a SQLite transaction across the script; the
file lock is the only thing that survives that implicit commit. `:memory:` skips
it: one process, private database.

```python
async def test_migrate_waits_for_a_process_that_holds_the_lock(tmp_path):
    """Split mode starts bot and worker together and both call `migrate()`.

    The guard is ``flock`` on ``<db>.migrate.lock``: the first process applies
    every pending script while the second waits, instead of reading MAX(version)
    before the first one commits and then failing on "table sites already exists".
    """
    import asyncio
    import fcntl

    path = tmp_path / "uwp.db"
    db = Database(path)
    await db.connect()
    holder = path.with_name("uwp.db.migrate.lock").open("a+")
    fcntl.flock(holder, fcntl.LOCK_EX)
    try:
        task = asyncio.create_task(db.migrate())
        await asyncio.sleep(0.2)
        assert not task.done(), "migrate() ignored the lock another process holds"
        fcntl.flock(holder, fcntl.LOCK_UN)
        await asyncio.wait_for(task, timeout=10)
    finally:
        holder.close()
        await db.close()
```

In `src/uwp/db/database.py` add `import fcntl` at the top and:

```python
    @asynccontextmanager
    async def _migration_lock(self) -> AsyncIterator[None]:
        """Hold ``<db>.migrate.lock`` for the whole migration pass.

        ``executescript`` commits any open transaction, so the "read
        MAX(version), then apply" guard cannot live inside one SQLite
        transaction: a second process reads the stale version and dies on
        "table already exists". A file lock outlives that commit. The file is
        created beside the database and never removed — deleting it would let
        two processes hold locks on different inodes.
        """
        if self.path == ":memory:":
            yield
            return
        lock_path = Path(f"{self.path}.migrate.lock")
        lock_path.parent.mkdir(parents=True, exist_ok=True)
        handle = await asyncio.to_thread(
            os.open, lock_path, os.O_CREAT | os.O_RDWR, 0o600
        )
        try:
            while True:
                try:
                    await asyncio.to_thread(
                        fcntl.flock, handle, fcntl.LOCK_EX | fcntl.LOCK_NB
                    )
                    break
                except BlockingIOError:
                    await asyncio.sleep(0.05)
            yield
        finally:
            # Closing the descriptor releases the lock; unlocking first would
            # leave a window in which a second process reads a half-applied set.
            await asyncio.to_thread(os.close, handle)
```

and wrap the body of `migrate()`:

```python
    async def migrate(self) -> None:
        """Apply pending migrations from ``uwp.migrations`` in filename order."""
        async with self._migration_lock():
            await self.conn.execute(
                "CREATE TABLE IF NOT EXISTS schema_version (version INTEGER NOT NULL)"
            )
            ...
```

```python
def _is_internal_host(host: str) -> bool:
    host = host.lower().rstrip(".")
    if host.startswith("[") and host.endswith("]"):
        host = host[1:-1]
    if host in _INTERNAL_NAMES:
        return True
    if any(host.endswith(suffix) for suffix in _INTERNAL_SUFFIXES):
        return True
    address = _parse_ip(host)
    if address is None:
        return False
    if isinstance(address, ipaddress.IPv6Address) and address.ipv4_mapped:
        address = address.ipv4_mapped
    # ``is_global`` rather than a list of flags: a target that is not routable
    # on the public internet has no business going out through a paid proxy.
    return not address.is_global


def _parse_ip(host: str) -> ipaddress.IPv4Address | ipaddress.IPv6Address | None:
    """Parse canonical and glibc-style spellings, or return ``None``.

    ``ipaddress`` rejects ``127.1``, ``0x7f000001`` and ``2130706433``, but
    ``inet_aton`` accepts all of them — and Chromium hands the bridge whatever
    the page wrote. A form the guard cannot parse must not be assumed public.
    """
    try:
        return ipaddress.ip_address(host)
    except ValueError:
        pass
    try:
        packed = socket.inet_aton(host)
    except OSError:
        return None
    return ipaddress.IPv4Address(packed)
```

- [ ] **Step 3: Rewrite `parse_version` and `compute_next`**

```bash
# `0.1b1` -> line `0.1`, serial `1`. `1.0.0` -> line `1.0.0`, no beta.
# The line keeps the number of parts it was written with; `release` never
# rewrites `1.0.0b1` to `1.0`.
parse_version() {
    local version=$1
    [[ $version =~ ^([0-9]+\.[0-9]+(\.[0-9]+)?)(b([0-9]+))?$ ]] ||
        die "не понимаю версию '$version': ожидаю 0.1, 0.1b2 или 1.0.0"
    LINE=${BASH_REMATCH[1]}
    SERIAL=${BASH_REMATCH[4]:-}
}
```

```bash
compute_next() {
    local current=$1 kind=$2
    local line serial major minor patch

    parse_version "$current"
    line=$LINE
    serial=$SERIAL
    major=${line%%.*}
    rest=${line#*.}
    minor=${rest%%.*}
    patch=""
    [[ $rest == *.* ]] && patch=${rest#*.}

    case $kind in
    beta)
        # A beta behind its own stable release is a downgrade: that line has
        # shipped. The next unseen one keeps the shape it was written with.
        if [[ -n $serial ]]; then
            echo "${line}b$((serial + 1))"
        elif [[ -n $patch ]]; then
            echo "$major.$minor.$((patch + 1))b1"
        else
            echo "$major.$((minor + 1))b1"
        fi
        ;;
    release)
        [[ -z $serial ]] && die "версия $line уже стабильная; выпуск без изменений не нужен"
        echo "$line"
        ;;
    minor)
        if [[ -n $patch ]]; then
            echo "$major.$((minor + 1)).0b1"
        else
            echo "$major.$((minor + 1))b1"
        fi
        ;;
    patch)
        [[ -z $patch ]] && die "версия $line без номера патча; patch требует X.Y.Z"
        echo "$major.$minor.$((patch + 1))b1"
        ;;
    major)
        echo "$((major + 1)).0.0"
        ;;
    *)
        die "неизвестный тип выпуска '$kind': ожидаю beta, release, minor, patch или major"
        ;;
    esac
}
```
