# v0.1b1 — первый публичный выпуск

Сервис работает целиком: Playwright запускает пропатченный Chromium
(`fingerprint-chromium`), Telegram-бот управляет расписанием, прокси и профилями,
результаты уходят в LibreOffice Calc `.ods`. Этот выпуск — бета: API и схема
базы ещё могут меняться, но обновление не теряет строк, потому что миграции
только добавляются.

## Что умеет

- **Парсеры как плагины.** Новый сайт — папка с одним классом в
  `src/uwp/parsers/`; ядро не меняется. Сломанный парсер записывается в отчёт о
  загрузке, а не роняет запуск.
- **Профили браузера.** Одноразовый (случайный отпечаток, чистые cookie) или
  постоянный — для сайтов со входом, живёт между прогонами.
- **Прокси на каждый сайт.** `http`, `https`, `socks5`; пароли шифруются в базе
  (Fernet, ключ растягивается PBKDF2).
- **Ручной вход через VNC.** Браузер на виртуальном экране за noVNC, ссылка и
  пароль приходят в чат. Один раз войти руками — дальше профиль работает сам.
- **Бот с кнопками.** Сайты, расписание, профили, прокси, история прогонов;
  постоянная клавиатура, настройка интервала, профиля, прокси, режима экспорта и
  параметров парсера.
- **Отчёты `.ods`** с автофильтром, кликабельными ссылками, подсветкой
  изменившихся строк и колонкой «Новое». Пишутся без запуска `soffice`.
- **Расписание** со случайным разбросом внутри интервала и одним догоняющим
  запуском.
- **Два режима развёртывания:** один процесс (`combined`) или два (`split`:
  `bot` + `worker`) на общей базе SQLite в WAL.

## Первый парсер

Steam — скидки. Читает региональные цены и отзывы с русской страницы магазина,
понимает разряды в ценах. В отчёте: скидка, цена в рублях, сводка отзывов,
ссылка на страницу игры.

## Безопасность

- Chromium работает **в песочнице**; `--no-sandbox` не используется. Профиль
  seccomp лежит в `docker/seccomp-uwp.json`, три послабления и их причины
  описаны в `docker/README-seccomp.md`.
- Порт noVNC публикуется только на `127.0.0.1`; для удалённого доступа нужен SSH-
  туннель или TLS-прокси.
- Прокси-мост слушает loopback и отказывает внутренним адресам (loopback,
  RFC 1918, link-local, `*.internal`, `*.local`), чтобы не стать путём к Docker
  socket или cloud metadata.
- Окружение процесса скрыто (`PR_SET_DUMPABLE=0`), переменные браузера идут по
  allowlist. Воркер не получает `UWP_BOT_TOKEN` вовсе.

Подробности и явный список того, что **не** защищено, — в `SECURITY.md`.

## Что известно ограниченным

- Один экземпляр на машину: оба стека публикуют порты 6000–6100 для noVNC.
- Нет встроенной авторизации кроме Telegram-админов и пароля noVNC; наружу
  выставлять без TLS-прокси нельзя.
- Откат на предыдущий выпуск не поддерживается — миграции только добавляются.

## Проверено

626 тестов, ruff чисто, на Python 3.12 и 3.14. Тесты не требуют ни сети, ни
браузера; живой прогон против Steam помечен `live` и включается через `UWP_LIVE=1`.

## Установка

```bash
git clone https://github.com/danilruntime/UltimateWebParser
cd UltimateWebParser
cp .env.example .env          # вписать UWP_BOT_TOKEN и UWP_ADMIN_IDS
docker compose -f compose.split.yaml -f compose.split.hostnet.yaml up -d --build
```

Через минуту напишите боту `/start`. Подробности, включая переменные окружения и
решение проблем, — в `README.md`.
