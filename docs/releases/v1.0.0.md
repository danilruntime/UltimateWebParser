# v1.0.0

Version `1.0.0`. Tag `v1.0.0`.

The first stable release. The service runs end to end, has been measured against
a live Steam deployment and a live SoundCloud page, and from here the version
follows semantic versioning: a breaking change to the API or the database schema
gets a new major number instead of appearing inside a beta series. Migrations
are still append-only, so an upgrade keeps every row.

## New

- A SoundCloud parser that reads the page's own `api-v2` responses: exact track
  values instead of the rounded text in the DOM, with hydration as the fallback.
- A parser can declare `auth_url` separately from `url`, so a VNC login opens
  the site's own login page instead of the page the parser scrapes.
- `scripts/release.sh major` and `patch`, and three-part versions: `0.1b3`
  becomes `1.0.0`, and `1.0.1b1` no longer has to pretend to be `1.1b1`.
- Installation instructions for Linux and Windows, in English and Russian.

## Fixed

- A `CONNECT` target written the way glibc accepts it (`127.1`, `0x7f000001`,
  `0177.0.0.1`, `2130706433`) reached the proxy bridge instead of being refused
  as an internal address. So did multicast, IPv4-compatible (`::127.0.0.1`) and
  NAT64 (`64:ff9b::a9fe:a9fe`, i.e. the cloud metadata address) literals.
- The bot and the worker could both start migrating the same fresh database and
  one of them died on "table already exists"; migrations are now serialised
  across processes, and the journal-mode switch retries instead of crashing the
  first of the two containers to open a new file.
- The same pair could both seed the example site and one died on "UNIQUE
  constraint failed"; the seed now holds one write transaction.
- A locked database left an `aiosqlite` thread running when `connect()` failed,
  so the process could not exit for Docker to restart it.
- An older image now refuses a database a newer one has migrated, as the install
  page already promised, instead of writing through a schema it misreads.
- An unbalanced IPv6 bracket in a request URI raised out of the proxy bridge's
  handler into the event loop.
- The image healthcheck probed the Telegram proxy online, so one slow probe
  could mark a working container unhealthy while compose's own check stayed
  offline.
- The missing-browser error named only `uwp browser install`, which writes into
  `data/browser` and does not put the binary on `PATH`; it now names
  `UWP_BROWSER_PATH` as well — in the terminal and in the bot's notice.
- A failed run kept its screenshot instead of losing it when the export was
  skipped.
- The login window refuses a download before it reaches the disk, instead of
  saving it silently or cancelling it without a trace.
- The browser build is pinned to 148, whose renderer survives the SoundCloud
  trending page.
- `uwp browser install` writes where it says it did, and the installed `chrome`
  is executable.

## Documentation

- `docs/install.md` covers Docker on Linux and Docker Desktop with WSL 2 on
  Windows, including why a native Windows run is not supported.
- Its commands run as written: every compose call carries its `-f` files, `exec`
  names the service `worker`, the check in the worker passes `--worker` (that
  service runs with an empty bot token on purpose, so plain `doctor` reports a
  healthy deployment as broken), and the uninstall note names the image the
  compose files actually build.
- The secret key is generated and pasted, not written as
  `UWP_SECRET_KEY=$(openssl rand -hex 32)` — `.env` is read by compose, not by a
  shell, so the old line made the literal text the key: it passes every length
  check and is printed on the page, so it protects nothing. `${...}` *is*
  expanded by Compose, and `doctor` now tells the two cases apart.
- `DISCLAIMER.md` states the lawful-use terms: terms of service, robots, no
  CAPTCHA bypass, personal data, and the operator's responsibility.
- The VNC section describes the kiosk rather than the desktop it replaced, and
  the parser guide names both shapes a parser can take.
- The SoundCloud parser and its captured fixtures are documented and attributed.
- The link check strips fenced blocks and inline code before it looks, so a
  quoted example is no longer reported as a broken link. `main` had been red
  since 2026-11-22 because of one (`v0.1b3` itself was clean).
